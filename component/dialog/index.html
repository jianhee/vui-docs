Dialog 对话框 ​

TIP

对话框和抽屉的 API 几乎完全一致，UI 略有差异。

示例 ​

示例说明

有些组件非常相似，比如 <VDialog> 和 <VDrawer> 组件，它们的示例也几乎相同，所以文档中使用了 <component> 组件来复用示例，它会根据路由地址动态渲染对应的组件，比如在 /component/dialog/ 页面中会渲染成 <VDialog> 组件，在 /component/drawer/ 页面中会渲染成 <VDrawer> 组件，使用时直接替换成对应的组件即可。

基础用法 ​

使用 v-model:visible 属性控制组件的显示和隐藏状态

<template>
  <DemoSpace flex>
    <VButton @click="onOpenDialog(1)">打开弹窗</VButton>
    <VButton @click="onOpenDialog(100)">内容溢出</VButton>
  </DemoSpace>

  <!-- 弹窗 -->
  <component
    :is="componentName"
    v-model:visible="isVisible"
    title="标题"
  >
    <div
      v-for="i in contentLength"
      :key="i"
    >
      内容
    </div>

    <template #footer>
      <VButton @click="closeDialog">关闭</VButton>
    </template>
  </component>
</template>

<script setup>
import { ref } from 'vue';
import { useDemoDialog } from '../composables';

// 区分类型
const { componentName, isVisible, openDialog, closeDialog } = useDemoDialog();
const contentLength = ref(1);
const onOpenDialog = lenght => {
  contentLength.value = lenght;
  openDialog();
};
</script>

自定义内容 ​

Dialog 组件由以下几部分组成

  1. 遮罩 Overlay
  2. 容器 Dialog
  3. 顶栏 Header，使用 header 插槽定义内容，或者使用 title 属性定义标题
  4. 主体 Body，使用 default 插槽定义内容
  5. 底栏 Footer，使用 footer 插槽定义内容
<template>
  <DemoUsage>
    <template #render>
      <DemoSpace flex>
        <VButton @click="openDialog">打开弹窗</VButton>
      </DemoSpace>
    </template>

    <template #config>
      <DemoField label="是否使用顶栏">
        <VSwitch v-model:checked="isShowHeader" />
      </DemoField>
      <DemoField label="是否使用标题">
        <VSwitch v-model:checked="isShowTitle" />
      </DemoField>
      <DemoField label="是否使用主体">
        <VSwitch v-model:checked="isShowBody" />
      </DemoField>
      <DemoField label="是否使用底栏">
        <VSwitch v-model:checked="isShowFooter" />
      </DemoField>
    </template>
  </DemoUsage>

  <!-- 弹窗 -->
  <component
    :is="componentName"
    v-model:visible="isVisible"
    :title="titleRef"
  >
    <template
      v-if="isShowHeader"
      #header
    >
      使用 header 插槽自定义的顶栏内容
    </template>

    <template
      v-if="isShowBody"
      #default
    >
      使用 default 插槽自定义的主体内容
    </template>

    <template
      v-if="isShowFooter"
      #footer
    >
      使用 footer 插槽自定义的底栏内容
    </template>
  </component>
</template>

<script setup>
import { ref, computed } from 'vue';
import { useDemoDialog } from '../composables';

// 区分类型
const { componentName, isVisible, openDialog } = useDemoDialog();

// 基础属性
const isShowHeader = ref(true);
const isShowTitle = ref(true);
const isShowBody = ref(true);
const isShowFooter = ref(true);
const titleRef = computed(() => (isShowTitle.value ? '使用 title 属性自定义的标题' : undefined));
</script>

自定义样式 ​

Dialog 会自动继承组件的 class 和 style 等属性，此外还可以使用 dialogClass、headerClass、bodyClass 、footerClass 等属性定义各部分的类名

<template>
  <VButton @click="openDialog">打开弹窗</VButton>

  <!-- 弹窗 -->
  <component
    :is="componentName"
    v-model:visible="isVisible"
    title="标题"
    style="width: 400px"
    class="c-demo-dialog-class1"
    :dialog-class="isDialog ? 'c-demo-dialog-class2' : ''"
    :drawer-class="!isDialog ? 'c-demo-dialog-class2' : ''"
    header-class="c-demo-dialog-header-class"
    body-class="c-demo-dialog-body-class"
    footer-class="c-demo-dialog-footer-class"
  >
    主体

    <template #footer> 底栏 </template>
  </component>
</template>

<script setup>
import { useDemoDialog } from '../composables';

const { componentName, isDialog, isVisible, openDialog } = useDemoDialog();
</script>

<style>
.c-demo-dialog-class1 {
  border: 1px solid blue;
}
.c-demo-dialog-class2 {
  background-color: pink;
}
.c-demo-dialog-header-class {
  color: #fff;
  background-color: red;
}
.c-demo-dialog-body-class {
  height: 400px;
  color: #fff;
  background-color: green;
}
.c-demo-dialog-footer-class {
  background-color: yellow;
}
</style>

样式属性和变量 ​

如果想要快速设置组件的某一个样式，可以使用组件的样式属性，或者使用属性对应的 CSS 变量。
类型格式示例说明
Vue 属性属性名="string|number"<VIcon size="20px" size="20" :size="20" />数值可以省略单位，内部会自动补全一个常用的值，比如 px
CSS 变量--vui-组件名-属性名: 值.vui-icon { --vui-icon-size: 20px; }数值不能省略单位，必须符合 CSS 语法
<template>
  <DemoUsage>
    <template #render>
      <VButton @click="openDialog">打开弹窗</VButton>
    </template>

    <template #config>
      <DemoField
        label="弹窗宽度"
        code="width"
      >
        <DemoSlider
          v-model:value="widthRef"
          unit="%"
          :min="15"
        />
      </DemoField>
    </template>
  </DemoUsage>

  <!-- 弹窗 -->
  <component
    :is="componentName"
    v-model:visible="isVisible"
    title="标题"
    :width="`${widthRef}%`"
  >
    内容
    <template #footer>
      <VButton @click="closeDialog">关闭</VButton>
    </template>
  </component>
</template>

<script setup>
import { ref } from 'vue';
import { useDemoDialog } from '../composables';

// 区分类型
const { componentName, isDialog, isVisible, openDialog, closeDialog } = useDemoDialog();
const defaultWidth = isDialog ? 50 : 30;

// 基础属性
const widthRef = ref(defaultWidth);
</script>

触发事件 ​

从打开到关闭依次触发 open、opened 、close 、closed 四个事件

<template>
  <VButton @click="openDialog">打开弹窗</VButton>

  <component
    :is="componentName"
    v-model:visible="isVisible"
    title="标题"
    @open="writeLog('open')"
    @opened="writeLog('opened')"
    @close="writeLog('close')"
    @closed="writeLog('closed')"
  >
    内容
    <template #footer>
      <VButton @click="closeDialog">关闭</VButton>
    </template>
  </component>
</template>

<script setup>
import { writeLog } from '@vp/utils';
import { useDemoDialog } from '../composables';

// 区分组件
const { componentName, isVisible, openDialog, closeDialog } = useDemoDialog();
</script>
