拖拽排序 ​

  • 使用 dragSortable 属性开启拖拽排序的功能，使用 dragSortGroup 属性定义两个组件之间的拖拽
  • 使用 canDropInto 属性可以将拖拽项移入目标项
  • 拖拽结束后触发 drag-sort-end 事件，然后手动处理源数据
