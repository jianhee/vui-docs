Button 按钮 ​

示例 ​

基础用法 ​

  • 使用 type 属性定义按钮类型
  • 使用 circle 属性定义是否为圆形按钮
<template>
  <!-- type -->
  <DemoSpace class="c-demo-btns">
    <VButton
      v-for="btnType in btnTypes"
      :key="btnType.label"
      :type="btnType.value"
      v-bind="$attrs"
    >
      {{ btnType.label }}
    </VButton>
  </DemoSpace>
  <!-- circle -->
  <DemoSpace
    v-if="isBasic"
    class="c-demo-btns"
  >
    <VButton
      v-for="btnType in btnTypes"
      :key="btnType.label"
      :type="btnType.value"
      circle
    >
      <VIcon icon="search" />
    </VButton>
  </DemoSpace>
</template>

<script setup>
import { useBasic } from '@vp/composables';

defineOptions({ inheritAttrs: false });
const { isBasic } = useBasic();

// 按钮类型
const btnTypes = [
  { label: 'Default', value: undefined },
  { label: 'Primary', value: 'primary' },
  { label: 'Info', value: 'info' },
  { label: 'Warning', value: 'warning' },
  { label: 'Error', value: 'error' },
  { label: 'Link', value: 'link' }
];
</script>

<style>
.c-demo-btns {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}
.c-demo-btns > .vui-btn {
  flex: none;
}
</style>

样式属性和变量 ​

如果想要快速设置组件的某一个样式，可以使用组件的样式属性，或者使用属性对应的 CSS 变量。
类型格式示例说明
Vue 属性属性名="string|number"<VIcon size="20px" size="20" :size="20" />数值可以省略单位，内部会自动补全一个常用的值，比如 px
CSS 变量--vui-组件名-属性名: 值.vui-icon { --vui-icon-size: 20px; }数值不能省略单位，必须符合 CSS 语法
<template>
  <DemoUsage>
    <template #render>
      <DemoBasic :radius="radiusRef" />
    </template>

    <template #config>
      <DemoField
        label="圆角尺寸"
        code="radius"
      >
        <DemoSlider v-model:value="radiusRef" />
      </DemoField>
    </template>
  </DemoUsage>
</template>

<script setup>
import { ref } from 'vue';
import DemoBasic from './basic.vue';

const radiusRef = ref(4);
</script>

API ​

基础属性 ​

名称说明类型默认值
type按钮类型string: default|primary|warning|error|linkdefault
circle是否为圆形按钮booleanfalse
loading是否为加载状态booleanfalse
icon前置图标VIcon.props.icon
iconProps前置图标的属性VIcon.props
size按钮尺寸string: large|medium|smallmedium
inline是否为行内模式（二选一）booleantrue
block是否为块级模式（二选一）booleanfalse
href点击跳转的地址，有值时 <button> 转为 <a> 标签string

原生属性 ​

原生属性的两种类型
  1. 比如 <VInput> 组件的 disabled 属性，组件内包含原生 DOM 元素，并且原生 DOM 元素支持这个属性，这类属性和原生属性完全一致
  2. 比如 <VSelect> 组件的 placeholder 属性，组件内不包含原生 DOM 元素，或者原生 DOM 元素不支持这个属性，这类属性是为了方便使用和理解而自定义的
名称说明类型默认值
disabled是否为禁用状态booleanfalse
