Checkbox 多选框 ​

TIP

多选框和单选框的 API 几乎完全一致，UI 略有差异，各自提供两个独立的组件

  1. <VCheckbox> 和 <VRadio> 用于单个选项
  2. <VCheckboxGroup> 和 <VRadioGroup> 用于选项组

Checkbox 示例 ​

示例说明

有些组件非常相似，比如 <VDialog> 和 <VDrawer> 组件，它们的示例也几乎相同，所以文档中使用了 <component> 组件来复用示例，它会根据路由地址动态渲染对应的组件，比如在 /component/dialog/ 页面中会渲染成 <VDialog> 组件，在 /component/drawer/ 页面中会渲染成 <VDrawer> 组件，使用时直接替换成对应的组件即可。

基础用法 ​

  • 使用 v-model:checked 属性绑定当前值
  • 切换选中状态时触发 change 事件
<template>
  <div class="c-demo-checkboxs">
    <component
      :is="componentName"
      v-for="item in checkboxItems"
      :key="item.label"
      v-model:checked="item.checked"
      v-bind="$attrs"
      :label="item.label"
      @change="showLog('change', $event)"
    />
  </div>

  <DemoSpace
    v-if="isBasic"
    class="c-demo-checkboxs"
  >
    当前值：
    <code
      v-for="item in checkboxItems"
      :key="item.label"
    >
      {{ item.checked }}
    </code>
  </DemoSpace>
</template>

<script setup>
import { ref } from 'vue';
import { useBasic } from '@vp/composables';
import { useItem } from '../composables/index.js';

defineOptions({ inheritAttrs: false });
const { isBasic, showLog } = useBasic();
const { componentName } = useItem();

// 当前值
const checkboxItems = ref([
  { checked: true, label: '选项1' },
  { checked: false, label: '选项2' },
  { checked: false, label: '选项3' }
]);
</script>

<style>
.c-demo-checkboxs > label {
  margin-right: 10px;
}
.c-demo-checkboxs > code {
  margin-right: 4px;
}
</style>

CheckboxGroup 示例 ​

基础用法 ​

  • 使用 v-model:value 属性绑定当前值
  • 使用 options 属性定义选项数组
  • 切换选项时触发 change 事件
<template>
  <component
    :is="componentName"
    v-model:value="checkedVal"
    route-suffix="Group"
    :options="options"
    v-bind="$attrs"
    @change="showLog('change', $event)"
  />

  <DemoSpace v-if="isBasic">
    当前值为 <code>{{ checkedVal }}</code>
  </DemoSpace>
</template>

<script setup>
import { ref } from 'vue';
import { useBasic } from '@vp/composables';
import { useGroup } from '../composables/index.js';

// 区分类型
defineOptions({ inheritAttrs: false });
const { isBasic, showLog } = useBasic();

// 选项
const options = [
  { value: 1, label: '选项1' },
  { value: 2, label: '选项2' },
  { value: 3, label: '禁用状态', disabled: true }
];

// 值
const { componentName, defaultVal } = useGroup(options);
const checkedVal = ref(defaultVal);
</script>

选项内容 ​

使用 default 插槽 > option.label 属性 > option.value 属性 > option 属性定义选项内容

<template>
  <component
    :is="componentName"
    v-slot="{ option }"
    v-model:value="checkedVal"
    route-suffix="Group"
    :options="options"
  >
    <template v-if="option?.slot">{{ option?.slot }}</template>
  </component>
</template>

<script setup>
import { ref } from 'vue';
import { useGroup } from '../composables/index.js';

// 选项
const options = [
  // Object
  { value: '选项1的value', label: '选项1的label', slot: '选项1的插槽' },
  { value: '选项2的value', label: '选项2的label' },
  { value: '选项3的value' },
  // string|number
  '选项4'
];

// 值
const { defaultVal, componentName } = useGroup(options);
const checkedVal = ref(defaultVal);
</script>

Checkbox/Group API ​

原生属性 ​

原生属性的两种类型
  1. 比如 <VInput> 组件的 disabled 属性，组件内包含原生 DOM 元素，并且原生 DOM 元素支持这个属性，这类属性和原生属性完全一致
  2. 比如 <VSelect> 组件的 placeholder 属性，组件内不包含原生 DOM 元素，或者原生 DOM 元素不支持这个属性，这类属性是为了方便使用和理解而自定义的
名称说明类型默认值
disabled是否为禁用状态booleanfalse
readonly是否为只读状态booleanfalse

Checkbox API ​

属性 ​

名称说明类型默认值
v-model:checked当前值，即是否选中booleanfalse
label选项文本string
type选项类型string: default|buttondefault
inline是否为行内模式（二选一）booleantrue
block是否为块级模式（二选一）booleanfalse

插槽 ​

名称说明
default选项内容，优先级高于属性值

事件 ​

名称说明参数
change切换选中状态时触发{ event: '事件对象', checked: '是否选中' }

CheckboxGroup API ​

属性 ​

名称说明类型默认值
v-model:value当前值，即选中项的 value多选框 Array[string|number]
单选框 string|number
options选项数组Array[object|string|number]
optionType选项类型string: default|buttondefault
optionInline选项是否为行内模式（二选一）booleanfalse
optionBlock选项是否为块级模式（二选一）booleantrue

属性.options ​

string|number 类型的选项会格式化为 { value, label }

名称说明类型
value选项值string|number
label选项文本，为空时使用 value 的值string|number
disabled是否禁用选项boolean

插槽 ​

名称说明参数
default选项内容，优先级高于属性值{ option: '当前项' }

事件 ​

名称说明参数
change切换选项时触发{ option: '当前项', value: '当前项的 value', checkedValue: '选中项的 value' }
