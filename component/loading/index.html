Loading 加载状态 ​

TIP

空状态和加载状态的 API 完全一致，UI 略有差异。

示例 ​

示例说明

有些组件非常相似，比如 <VDialog> 和 <VDrawer> 组件，它们的示例也几乎相同，所以文档中使用了 <component> 组件来复用示例，它会根据路由地址动态渲染对应的组件，比如在 /component/dialog/ 页面中会渲染成 <VDialog> 组件，在 /component/drawer/ 页面中会渲染成 <VDrawer> 组件，使用时直接替换成对应的组件即可。

基础用法 ​

<template>
  <component :is="componentName" />
</template>

<script setup>
import { useEmpty } from '../composables';
const { componentName } = useEmpty();
</script>

自定义图标 ​

使用 icon 和 iconProps 属性定义图标

<template>
  <DemoSpace flex>
    <DemoField
      label="不使用图标"
      label-position="top-center"
    >
      <component
        :is="componentName"
        :icon="null"
      />
    </DemoField>
    <DemoField
      label="自定义图标"
      label-position="top-center"
    >
      <component
        :is="componentName"
        icon="face"
      />
    </DemoField>
    <DemoField
      label="自定义样式"
      label-position="top-center"
    >
      <component
        :is="componentName"
        :icon-props="{ color: 'pink', size: 100 }"
      />
    </DemoField>
    <DemoField
      label="自定义图标和样式"
      label-position="top-center"
    >
      <component
        :is="componentName"
        icon="face"
        :icon-props="{ color: 'pink', size: 100 }"
      />
    </DemoField>
  </DemoSpace>
</template>

<script setup>
import { useEmpty } from '../composables';

const { componentName } = useEmpty();
</script>

自定义图片 ​

使用 image 和 imageStyles 属性定义图片

<template>
  <DemoSpace flex>
    <DemoField
      label="自定义图片"
      label-position="top-center"
    >
      <component
        :is="componentName"
        :image="image"
      />
    </DemoField>
    <DemoField
      label="自定义图片和样式"
      label-position="top-center"
    >
      <component
        :is="componentName"
        :image="image"
        :image-styles="{ width: '400px' }"
      />
    </DemoField>
  </DemoSpace>
</template>

<script setup>
import loadingImg from '@vp/images/loading.gif';
import emptyImg from '@vp/images/empty.png';
import { useEmpty } from '../composables';

// 区分类型
const { isEmpty, componentName } = useEmpty();
const image = isEmpty ? emptyImg : loadingImg;
</script>

布局方向 ​

<template>
  <DemoUsage>
    <template #render>
      <component
        :is="componentName"
        :direction="directionRef"
      />
    </template>

    <template #config>
      <DemoField
        label="布局方向"
        code="direction"
      >
        <DemoSelect
          v-model:value="directionRef"
          :options="directionItems"
        />
      </DemoField>
    </template>
  </DemoUsage>
</template>

<script setup>
import { ref } from 'vue';
import { useEmpty } from '../composables';

const { componentName } = useEmpty();
const directionItems = ['vertical', 'horizontal'];
const directionRef = ref(directionItems[1]);
</script>

样式属性和变量 ​

如果想要快速设置组件的某一个样式，可以使用组件的样式属性，或者使用属性对应的 CSS 变量。
类型格式示例说明
Vue 属性属性名="string|number"<VIcon size="20px" size="20" :size="20" />数值可以省略单位，内部会自动补全一个常用的值，比如 px
CSS 变量--vui-组件名-属性名: 值.vui-icon { --vui-icon-size: 20px; }数值不能省略单位，必须符合 CSS 语法
<template>
  <DemoUsage>
    <template #render>
      <component
        :is="componentName"
        :padding="paddingRef"
      />
    </template>

    <template #config>
      <DemoField
        label="上下间距"
        code="padding"
      >
        <DemoSlider
          v-model:value="paddingRef"
          unit="px"
        />
      </DemoField>
    </template>
  </DemoUsage>
</template>

<script setup>
import { ref } from 'vue';
import { useEmpty } from '../composables';

// 区分类型
const { componentName } = useEmpty();
const paddingRef = ref(30);
</script>

- true 使用默认图标

description自定义描述文本- false|null 不使用文本
- true 使用默认文本
- string 使用自定义文本		true

- VLoading : Loading...|加载中...
direction布局方向string = vertical|horizontalvertical
